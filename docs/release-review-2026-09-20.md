# 2026-09-20 源码与安装包检查

检查对象是 VeryMath/VeryMath-textbook-copilot 的主分支 `a55fd77` 和 [v0.2.1 发布页](https://github.com/VeryMath/VeryMath-textbook-copilot/releases/tag/v0.2.1)上的两个安装包。本地已从原来的 `637f248` 更新到该主分支，修复位于 `codex/review-release-bugs`。没有推送或替换 GitHub 安装包。

## 结论

原发布包能启动，但包含影响模型连接、问答和学习资料生成的功能问题。下面的核心问题已在本地修复；Windows 安装后的完整运行仍需实机验证，不能把打包成功视为功能全部通过。

| 使用者 | 触发操作与问题 | 影响与严重程度 | 证据 | 处理 |
| --- | --- | --- | --- | --- |
| 普通用户 | 模型地址不可达，请求失败后仍收到完成事件 | 高：界面可能只显示“已完成”，没有回答，也不告诉用户哪里出错 | 在发布的 macOS 包内运行环境中实际复现；旧结果只有 progress、done | 已处理助手最终错误，失败返回 error；源码的无范围与当前页请求均验证通过 |
| 普通用户 | 保存 Anthropic、OpenAI 等内置服务商的 Key 后重启 | 中：Key 丢失，需要反复填写 | 临时数据目录中实际配置、销毁运行时、重新初始化复现 | 各服务商 Key 统一保存在已有 agent/auth.json，重启后可读 |
| 普通用户 | 输入服务商 A 的 Key，再切换到服务商 B | 高：旧 Key 留在输入框，可能保存到错误服务商 | 源码确认；修复后页面操作确认切换会清空密钥与未保存的地址 | 成功保存后清空 Key，切换时清空草稿并隔离模型列表 |
| 普通用户 | 默认“无范围”下点击生成课件、图谱，或结合辅助资料提问 | 高：跳过所选 Skill、模板和成品处理，丢弃所选资料 | 前后端分支静态确认；页面实际确认修复后选择教材工具会切到当前页 | 合并重复发送与执行分支，保留资料、成品、模板和图谱深度；无范围仍不附当前教材正文 |
| 开发者 | 使用 npm run dev 或 Vite 预览访问模型接口 | 高：模型状态与工具接口返回 500 | 实际请求复现 ModelRuntime 尚未初始化；修复后两个模式均返回 200 | 启动接口前等待模型服务初始化 |
| 普通用户 | 为内置服务商填写 Base URL，或切换服务商 | 高：保存的地址不用于实际请求，旧服务商模型可能串入新服务商 | 真实 SDK 确认静态模型查找忽略地址覆盖；修复后模型对象使用保存地址 | 按服务商保存地址，使用运行时模型查找；地址可回填、清空恢复默认；切换服务商不继承旧模型 |
| Windows 用户 | 在未安装 Bash 的电脑上执行课件编译等命令任务 | 高：原包只启用 Bash，调用命令时可能报 No bash shell found | Windows EXE 解包与依赖源码确认；没有 Windows 实机执行 | 已改为 Windows 使用 SDK 内置 PowerShell，并修正包内 Node 的调用提示；SDK 工具启用检查通过，实机执行待验 |

| Windows 用户 | PATH 中没有 unzip 时上传 DOCX/PPTX | 中：正文提取和全文搜索失败 | 原安装包不含 unzip.exe；提取代码直接调用系统 unzip；未在 Windows 实机复现 | 尚未修改；当前需安装 unzip，后续可改为应用内 ZIP 读取 |

## 实际做过的验证

- 拉取指定 VeryMath 仓库，检查主分支、发布资产及 Windows 构建记录。
- 下载并挂载原 macOS DMG，实际打开桌面窗口；包内服务首页、教材 PDF 和 PDF 字体接口返回 200。
- 使用发布包自带的运行环境读取真实教材第 8 页，生成正文和页面 PNG，并查看了图片，文字与公式正常。
- 在隔离课程目录使用不可达的本机地址执行真实请求，确认原包错误地返回 done；修复后的请求返回明确错误与重试进度。没有调用付费模型。
- 验证 Key 保存与重启、服务商切换、Base URL 保存与清空、手工多模型配置、逐模型地址与配置保留。
- 在页面验证服务商切换清空输入，以及教材工具从“无范围”切到当前页。
- TypeScript 检查、生产构建、后端语法检查和 Git 差异检查通过。macOS arm64 DMG 可重新构建；安装包没有上传。
- 最终重新打包后的课程服务返回 200，真实教材导入返回 201；不可达模型地址的请求最终返回 error，不再返回 done。本地安装包位于 `release/VeryMath-local-review-arm64.dmg`（约 276 MiB），内部版本沿用 0.1.0，不是新的 GitHub 发布。
- 下载并解包 Windows EXE，确认 Windows x64 Canvas 原生模块存在。现有 Windows 工作流只执行内嵌 Node 的版本命令，没有安装向导、模型问答或课件生成的完整验证。

## 验证范围的限制

本次没有 Windows 真机或虚拟机，没有执行使用有效模型账号的完整问答、课件生成、OCR 和视频任务。因此，范围与资料处理修复经过代码核对和页面检查，不能据此声称模型已经成功生成全部类型的学习资料。外部 XeLaTeX、OCR 和 unzip 的安装仍按现有依赖要求处理。

建议先使用本地修复版复核核心流程，再统一版本号并发布。GitHub 上原 v0.2.1 安装包仍包含本报告所列的原有问题。
