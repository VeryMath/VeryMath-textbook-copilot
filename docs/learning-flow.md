# 围绕知识点的学习流程

## 目标体验

**在知识图谱选一个知识点 → 讲解 → 做一道题 → 根据实际错误补讲 → 再做一道变式题。**

学生可以随时追问、查看教材或停止练习。

## 已有基础

- 学习资料可作为 Copilot 的对话上下文。
- 内容讲解 Skill 已加强符号、推理跳步、适用条件等具体卡点的解释。
- 出题支持逐题卡片、渐进提示和默认隐藏的答案；提交时将当前题目与实际作答发给 Copilot。
- 作答与反馈随对话保存在个人课程目录；当前页面的卡片草稿暂存于界面。
- 卡片已有“针对这道题再练一道”入口，Agent 可结合题目和已有反馈生成新练习。

## 下一步打通

1. **从具体知识点开始。** 将图谱中选中的节点及其教材依据传给讲解、出题；在界面上显示正在学习哪个知识点，避免只传整份图谱。
2. **把作答关联到具体题目。** 记录课程、知识点、练习资料、题目、作答与反馈之间的关系，保存在个人课程文件夹。支持回来继续练习，而不只依靠对话中的题干文字定位。
3. **围绕实际困难补讲。** 根据学生答案区分概念错误、推理缺口和计算失误，补讲首个关键问题；接受正确的不同解法，不按答案字符串判数学题。
4. **自然衔接变式题。** 反馈后提供“补讲这里”“再练一道”等操作，自动携带当前题目和相关反馈。补练默认一道，保留原题和作答，方便比较前后理解。

## 分工与边界

- 前端负责选中知识点、展示题目和操作入口；本机服务保存关联与记录；课程 Agent 调用讲解、出题 Skill 完成教学内容。
- Skill 负责怎么教和怎么出题；节点选择、题目关联、记录恢复和操作衔接需要程序配合，不能只增加提示词。
- 只依据实际作答或学生明确指出的困难安排补练，不凭一次表现断言“已掌握”或“完全不会”。
- 复用现有反馈与补练入口，连接知识点、题目和学习记录。

## 完成时应能做到

选中一个知识点后，无需反复复制上下文即可完成讲解、作答、针对性补讲和一道变式；重新打开课程后，能找到原题、此前作答与反馈，并继续学习。
