# 数学与算法实验

## 目标体验

**从教材中的数学问题出发 → 改变参数或选择方法 → 真实运行 → 对比图形与数值 → 结合理论解释观察到的现象。**

实验与当前教材知识点关联，可从讲解或图谱进入。

## 首个示例：步长如何影响梯度下降

- 选择一个便于理解和绘图的二次函数，明确目标函数、初始点与停止条件。
- 调整步长，观察迭代轨迹和目标函数随迭代次数的变化，比较收敛快慢、振荡或发散。
- 对比时保持问题和初始点等其他条件相同，注明每条曲线采用的参数。
- 让学生先预测，再运行观察；Agent 根据实际结果解释现象，并联系教材中的步长条件。数值现象与一般数学结论分开说明。

后续扩展：梯度下降与动量方法的比较、正则化参数的影响、条件数与收敛速度、算法适用条件。

## 应交付的内容

- **真实结果**：实际运行的参数、迭代记录、停止原因，以及适合该实验的误差或目标值。
- **可读图形**：轨迹、收敛曲线或方法对比图，标清坐标、图例与参数。图形由运行数据绘制，不能用文生图代替数值实验结果。
- **可运行代码**：保存本次使用的代码、参数和必要的运行说明，方便学生理解、修改和复现。
- **教学解释**：说明结果支持什么、为什么出现差异，以及当前实验不能据此推出什么。

## 实现分工与待办

- 前端提供参数输入、方法选择、运行与停止、结果对比、代码查看等操作，默认值来自具体实验内容。
- 课程 Agent 调用实验 Skill，结合教材构建问题、执行代码、绘图并解释结果。
- 本机服务将代码、参数、数据和图形保存在个人课程的 outputs 子目录；切换实验后仍可查看以前的结果。
- 区分“重新运行”和“查看已有结果”，展示运行中、完成或失败状态；参数改变后不能继续把旧图标成新结果。
- 运行失败、达到迭代上限或发散时如实显示，并解释可能原因，不编造成功曲线。

## 与学习流程衔接

与 [围绕知识点的学习流程](learning-flow.md) 共用教材与知识点上下文。学生做错题时，可以用一个小实验辅助补讲；观察实验后，也可以生成一道预测或解释现象的练习。是否运行实验由学习需要决定，不强制插入每次讲解。
