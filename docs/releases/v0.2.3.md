# VeryMath 0.2.3

## 更新内容

- 桌面版启动时和运行期间每六小时检查一次 GitHub 正式版本。发现更新时可以先查看说明，确认后下载安装包。网页版提供新版本提示与发布页链接。
- 课程服务增加访问校验。Agent 按本次选择的范围读取教材和资料，生成文件保存在当前任务目录。打开生成的 SVG 时禁止执行脚本。
- PPTX 正文按演示顺序逐页提取，并限制累计解压量和处理时间。

## 升级说明

- 使用自定义模型服务地址的用户需要在工作区设置中重新保存 API Key。
- 课件支持文字页面和 LaTeX 源码 ZIP。PDF 自动编译和新视频生成暂不可用，已有 PDF 和视频仍可查看。
- 从源码运行需要 Node.js 22.19 或更新版本。
