# 教材课件生成

## 目标

依据教材的知识结构，使用 LaTeX Beamer 编写并编译章节课件，支持教师自行选取、组合和讲解。默认交付 PDF 幻灯片，每个 PDF 页面对应一张幻灯片，默认采用 16:9 横向页面。课件的组织依据是教材章节、小节及知识内容。每章的页数由内容和讲解所需的展开程度决定。

在 VeryMath 智慧教材中执行时，先阅读 [课程输入、编译与结果返回](references/course-copilot.md)，使用本轮提供的教材路径、操作范围、输出目录和结果 ID。以下规则用于组织实际课件内容。

## 讲解顺序

生成正文前，阅读 [教材内容的讲解顺序](references/explanation-order.md)。先确定目标小节在教材中的作用和需要回答的问题，再按理解依赖安排例子、定义、条件、推导与结论。在工作记录中列出逐页讲解顺序，说明各页之间的联系，然后编写 LaTeX。整份课件使用教师在课堂上解释知识的自然语气，按参考文件中的“课堂讲解的语气”和“页面文字的取舍”编写与检查。

章节和小节决定文件组织。小节内部的页面顺序依据概念和推理的理解需要安排，教材中的例子可以在首次需要解释相应概念时引入。

## 1. 教材结构

- 先读取教材目录，再核对目标章节正文中的标题层级、编号与实际内容。
- 按教材的章、小节及更细一级标题建立内容顺序，沿用原有编号和名称。
- 全书任务先整理完整目录，再逐章生成。指定章节任务同时查阅该章需要引用的预备知识。
- 用户指定内容范围或组织方式时，按用户要求安排，并保存内容与教材原章节的对应关系。
- 当前页和选中内容任务按指定内容制作局部课件，标题使用当前小节编号与名称，所属章节记录在 PDF 书签和源码注释中。整章和整书任务通过教材目录确定完整范围。

## 2. 文件组织

- 每章生成一份独立的 `.pdf` 文件，文件名包含章号和章名，例如 `第03章-梯度方法.pdf`。
- 章内按教材小节顺序编排，并建立对应的 PDF 书签。教师能够通过书签和页面缩略图辨认各小节的起始位置和内容范围。
- 教材中的附录按其原有结构单独组织；章节正文引用附录时注明对应位置。
- 用户要求合并时，通过组合入口文件按指定顺序载入章节或小节的 LaTeX 正文，重新编译，更新整份 PDF 的页码、目录和书签。

## 3. 章节结构

- 整章课件的起始标题使用章号与章名；局部课件的起始标题使用当前小节编号与名称。章节较长时，可增加一页列出教材小节的目录。
- 各小节依次展开。小节开始处呈现完整的小节编号和名称，可直接与该小节第一页的实质内容共同排版。
- 教材已有本章总结时，按原有内容组织总结页。另行编写总结时，内容应能逐项对应本章讲解过的知识。
- 章节中的例题、证明、算法和重要说明放在相关知识附近，使阅读顺序与理解顺序一致。

## 4. 章内内容分组

- 围绕一个可识别的知识内容安排一组连续幻灯片，例如一个定义、一个定理及其证明、一种算法，或一道例题。
- 每组内容通过题目、条件、推导和结果解释呈现其数学含义与知识依赖。教师据此选取所需内容。
- 同一知识内容需要多页时，使用明确的连续标题，例如“定理 3.2：条件与结论”“定理 3.2：证明”“定理 3.2：应用”。
- 小节内有多个知识内容时，按教材的逻辑关系依次组织。紧密相关的推导、图示和例题保持相邻。
- 一组内容的第一页应提供理解本组所需的局部背景。后续页新出现的符号应在首次使用处说明。

## 5. 内容覆盖与展开

- 默认覆盖目标范围内各节的实质内容，包括定义、定理及其条件、证明、算法、例题和重要解释。
- 根据内容复杂性安排页数。较长证明和计算按推理步骤拆页，各页写明本步目标及使用的条件。
- 定理的条件与结论共同构成完整陈述，排版时保证读者可以明确对应两者。
- 算法内容交代适用问题、输入、主要步骤、输出，以及教材给出的适用条件和性质。
- 例题包含题目、解题过程和结果解释。贯穿讲解的例子在相关知识首次出现时引入，后续计算沿用相同名称和编号；独立例题的题目与解答连续排列。
- 教材习题保持独立的小节或章节末尾位置。习题解答的生成范围由用户要求确定。
- 补充解释、补充例题和延伸材料的性质及出处记录在源码注释中。页面标题直接说明所讲解的学科主题。

## 6. 跨小节与跨章节依赖

- 引用其他位置的知识时，使用教材章节号、内容名称及原有编号，例如“第 2 章，定理 2.3：凸函数的一阶条件”。
- 被引用的条件、定义或公式直接影响当前推导时，在当前内容附近简要重述，并注明教材位置。
- 对“如前所述”“根据上面的结果”等依赖排列位置的表述，补充具体的概念名称、定理编号或公式编号。
- 合并或重新排序后，逐项检查跨页引用，使读者能通过名称和教材编号找到对应内容。

## 7. 全书一致性

- 整份课件的数学记号以教材原文为准。这项要求适用于全部章节和全部页面，包括封面、标题、正文、公式、图表、例题、证明、算法、总结和附录。同一对象始终沿用教材的记号、上下标、维度与含义。各章共享标题层级和版式约定，术语译法遵循教材。
- 编写前在工作记录中整理目标范围的符号及含义。补充例子直接使用教材中的变量及其分量，数值代入保持相同记号。确有新增对象时，在首次出现处定义相应符号，并检查与教材已有符号的冲突。
- 教材对同一符号有局部重新定义时，在相应内容起始处说明该符号的含义及适用范围。
- 定义、定理、公式、图表和例题沿用教材已有编号，便于独立使用章节及组合多章时定位。
- 课件页码按当前文件中的顺序编排。教材内容编号用于表达知识对应关系。

## 8. 教材位置记录

- 起始页使用当前内容的标题。上级章节路径记录在 PDF 书签和源码注释中。教材名称、作者、版本、出版或手稿日期记录在章节入口的源码注释中。各页对应的教材章节、原书页码、PDF 页序及原始公式、图表或例题编号，写入相应 `frame` 前的 LaTeX 源码注释。
- 页脚采用简洁的幻灯片页码。教材位置对应、公式校对过程和制作说明统一记录在源码注释中。
- 教材印刷页码与 PDF 文件页序不同的情况下，分别写明，例如“教材第 35 页，PDF 第 47 页”。
- 同一页内容涉及多个教材位置时，分别列出对应关系。

## 9. 结构检查

- 按讲解顺序检查本节问题、逐页衔接、公式引入理由和例子的作用，确认结尾回答了本节的问题。
- 对照目标章节目录与正文，检查各小节以及主要知识内容的覆盖情况。
- 检查每组连续内容的条件、符号、推导和结果能否完整对应。对照教材逐页检查整份课件所有位置的符号使用，清理自行引入的同义参数和中途换名。
- 检查小节起点是否清楚，题目与解答、定理与证明、算法与解释是否便于一起选取。
- 检查跨章依赖是否能通过明确的教材位置找到，独立使用时所需的局部说明是否齐全。
- 检查章节文件名、标题、原书编号与源码注释中的教材位置是否一致。
- 检查最终 PDF 的页面比例、小节书签和页码，以及文字、公式、图表的渲染结果。每页应能完整呈现当前步骤所需的内容。

## 10. LaTeX 源文件与编译

- 编写和修改课件时，阅读 [Beamer 模板](references/beamer-templates.md)，使用对应的模板资源并遵循模板选择规则。
- 使用 Beamer 文档类，默认页面比例设为 `aspectratio=169`。中文课件使用 `ctex` 配置中文排版，默认使用 XeLaTeX 编译，并确认所用字体在当前环境中可用。
- 数学排版优先采用美国数学学会（AMS）的 `amsmath`、`amsfonts`、`amssymb` 宏包，数学字体优先使用 Computer Modern 配合 AMS Fonts。`amsmath` 提供数学排版环境，具体字形由数学字体提供。Beamer 中使用 `\usefonttheme[onlymath]{serif}` 配置衬线数学字体；数学字体设置统一放在 `preamble.tex` 中。
- 优先数学字体不可用时，回退到编译环境的默认数学字体。回退后逐页核对上下标、希腊字母、黑板粗体、粗体向量及特殊符号，确认其含义与教材一致；缺字和替代字体情况记录在源码注释中。
- 全书共用一份 `preamble.tex`，集中定义宏包、字体、颜色、页眉页脚及数学命令。各章节入口加载这份文件。
- 每章具有可独立编译的入口 `.tex` 文件，负责声明文档类、加载公共设置、设置章节标题及载入本章正文。
- 按教材小节保存正文 `.tex` 文件，正文包含小节标题和相应的 `frame` 环境。章节入口使用 `\input` 按顺序载入这些文件。
- 每个小节的正文维护在对应源文件中。组合入口通过 `\input` 引用所选内容，并与章节入口共用排版设置。图片路径统一以课件项目根目录为基准，从项目根目录执行编译。
- 用 `\section` 表达教材的章，用 `\subsection` 表达教材的小节。标题中写明教材原有编号，目录与 PDF 书签遵循这一层级。
- 每个 `frame` 默认完整呈现一页。分步推导通过连续的 `frame` 展开，逐页呈现所需条件和当前推导步骤。
- 公式使用 LaTeX 数学命令排版。需要拆页时，按推理关系安排公式及其解释，并保持教材公式编号明确可辨。
- 引用标签包含教材章号和小节号，例如 `ch03-sec02-descent`，保证跨章组合后的标签唯一。
- 编译完成后检查错误、未解析引用、字体缺失及内容溢出，并渲染 PDF 逐页检查。将编译命令与采用的引擎记录在入口文件的源代码注释中。
- 交付各章 PDF，在课件项目中保存入口文件、小节正文、公共设置及所引用的图片，支持后续修改和重新编译。
