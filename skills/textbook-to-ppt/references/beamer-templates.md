# Beamer 模板

## 模板选择

| 模板 ID | 名称 | 版式 |
| --- | --- | --- |
| navy | 白底深蓝 | 左对齐标题、蓝色细线、浅蓝公式框 |
| ivory | 米白宋体 | 居中标题、宋体正文、棕红强调色、细线分隔 |
| banner | 蓝色标题栏 | 通栏深蓝标题、白底正文、青蓝强调色 |

新建课件默认使用 `navy`。按用户在界面或正文中的选择使用对应模板。修改已有课件时，沿用源码中的模板；用户指定新的样式时，使用所选模板重新编译并检查全篇排版。应用传来的 `templateId` 记录课件所用的内置模板，用户正文中的明确要求优先。

## 资源与使用

模板资源位于本 skill 的 `assets/beamer/`。VeryMath 智慧教材会提供可用模板资源目录的绝对路径。

1. 将 `assets/beamer/preamble.tex` 复制到当前课件项目根目录。
2. 将所选 `assets/beamer/themes/<模板ID>.tex` 复制到当前项目的 `theme.tex`。公共设置通过 `\input{theme.tex}` 加载版式。
3. 章节入口采用 `\documentclass[aspectratio=169,11pt]{beamer}`，并加载 `\input{preamble.tex}`。小节正文按讲解内容单独编写。
4. 全书共用这份公共设置和主题。新增数学命令沿用教材记号，保存在当前项目公共设置中。图形和数值例子按教材内容编写。
5. 修改课件并切换模板时保留公共设置中的学科命令，更新 `theme.tex`，检查标题、公式、定理和图形在所有页面中的位置。

`Page`、`Ink`、`Accent`、`Muted`、`Highlight` 和 `Panel` 分别用于背景、正文、强调色、辅助文字、图形重点及内容框，图形可引用这些颜色名。数学排版遵循 SKILL.md 的字体规则。

蓝色标题栏按单行标题设计；标题较长时，缩短到当前页面的知识主题，或按实际行数调整当前项目的标题栏高度。复杂内容依据推理步骤拆页。

交付源码 ZIP 时同时包含 `preamble.tex`、`theme.tex`、章节入口、小节正文及引用资源。对项目模板的调整保存在本轮输出目录中。
